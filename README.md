# 邻里药箱 · 社区共享借用 / 效期提醒 / 邻里互助（演示）

一个纯前端演示应用：居民登记家中多余但**未拆封**的常备非处方耗材（退热贴、碘伏、纱布、创可贴、口罩、体温计电池等），
经社区志愿者审核发布后，邻居可按症状场景申请借用，支持自取 / 志愿者代送 / 邻居门口无接触交接，交接拍照确认，
并按约定归还或补充。效期临近、多人争抢、超时未取、配送延误、共享人撤回、包装破损与使用后不适均有对应处理流程。

> **社区只做物品流转和风险提醒，不做诊断建议。**
> 处方药、拆封药品、冷链药品、过期/包装破损物品**一律不能进入共享**。共享物品不替代就医。

## 本期重点：使用后不适反馈 → 同批次立即冻结 → 社区核查分流

借用人使用碘伏后反馈皮肤红肿时，系统按以下闭环处理（对应需求“扩展不适反馈后的物品冻结”）：

1. **结构化上报**：反馈人勾选**症状表现**（红肿/瘙痒/起水疱/呼吸不畅等），填写**过敏史、使用方式（部位/用量）、包装照片、是否就医及就医情况**。
2. **立即冻结同批次**：提交瞬间，同品类、同**生产批号**的全部剩余物品立即冻结（含尚在待审核的同批物品），
   候补/已确认/交接中的申请**全部自动取消**；已取走的借用保留并提醒停止使用、保留包装、观察就医。
3. **三方通知**：通过站内消息（右上角 🔔）通知**共享人、社区工作人员/志愿者、已借用居民和被取消的在途申请人**。
4. **社区核查分流**：工作人员依据回访与就医记录，在结构化核查表单中选择结论：
   - **个体过敏 / 个体反应** → 同批物品核验合格后**恢复共享**，并对该品类发布**风险提醒**（之后借用必须勾选知情确认）；
   - **物品问题（批次/包装/质量）** → 同批次剩余物品**全部下架报废**，按医疗/有害垃圾处理；
   - **暂无法判定** → 解除冻结继续观察，再次出现同类反馈将重新冻结。
   结论写入物品时间线并通知全部相关居民。
5. **冻结期间防扩散**：被冻结物品从大厅隐藏；仍想申请同类物品的居民在大厅与详情页会看到
   “**该品类有批次正在核查**”提示，系统推荐**不同批次的同类物品、其他安全替代方式（清水冲洗等）与就医渠道**（120/社区卫生站/区医院/社区热线）。

技术栈：Vue 3（`<script setup>`）+ TypeScript + Pinia + Vue Router + Vite + Vitest。
所有数据保存在浏览器 `localStorage`，无后端依赖；底部“演示时钟”可快进，用于演示效期、超时与延误。

## 本地启动

### 方式一：Node 直接运行

```bash
npm install        # 如本机 npm 缓存权限异常，可加 --cache /tmp/npm-cache
npm run dev        # http://localhost:5173
```

### 方式二：Docker / Compose 一键启动（无需本机 Node）

```bash
docker compose up -d --build
# 打开 http://localhost:8080
docker compose logs -f
docker compose down
```

镜像为多阶段构建：Node 20 构建静态产物 → nginx 1.27 托管（含 SPA 路由回退与健康检查）。

其他命令：

```bash
npm run typecheck  # vue-tsc 严格类型检查
npm run test       # Vitest 单元/流程/页面冒烟测试（3 个文件，33 个用例）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览构建产物
```

## 页面与角色视图

- **药箱大厅 `/hall`**：按四个急用场景筛选 + 关键词/批号搜索；仅展示审核通过、在有效期内、**未被批次冻结**的物品；
  品类有批次核查时置顶显示警示条与安全替代/就医渠道；卡片显示批号、来源、效期分级、余量/候补人数与品类风险提醒。
- **物品详情 `/items/:id`**：显示生产批号/厂家；借用前强制逐项确认 **来源 / 效期批号 / 包装状态 / 适用限制**（有品类风险提醒时额外强制知情确认）；
  “反馈包装破损 / 使用后不适”打开结构化上报面板；冻结时展示冻结横幅与**安全替代+就医渠道**卡片；
  同页展示借用记录、含核查结论的反馈记录与完整时间线。
- **登记共享 `/register`**：填写品名、规格、**生产批号/厂家**、有效期、存放条件、是否整盒未开封、数量、地点、场景；
  实时规则校验，禁入品（处方药/口服注射药、拆封、冷链、过期）提交即被拦截；缺批号给出“无法同批次联动冻结”的提示。
- **我的共享 `/my-shares`**：登记物品状态与审核意见；同批冻结时展示原因与后续处理说明；确认/婉拒申请、交接拍照、撤回。
- **我的借用 `/my-borrows`**：候补、取件/拍照确认、归还补充；**已取走物品若同批被冻结，红色横幅提醒立即停用、保留包装并就医**。
- **志愿者工作台 `/volunteer`**：审核（冻结批次的审核按钮禁用）、配送拍照/报备延误/改派、超时催办与释放、候补递补。
- **社区工作台 `/staff`**：结构化核查面板（症状/过敏史/用法/照片/就医信息 + 冻结范围 + 三种结论表单）、
  生效中的品类风险提醒、过期报废、60/30 天效期分级、“其他耗材”双重复核、任选物品查看完整链路时间线。
- **互助边界 `/guide`**：禁入品类、借用前确认事项、七种异常处理（含“个体过敏还是物品问题”的分流规则）。

## 关键业务规则（可在 `src/rules.ts` 与 `src/stores/medkit.ts` 核验）

- **同批次判定**：同品类 + 同生产批号（去空格、不区分大小写）；无批号的物品不参与自动联动冻结，只冻结反馈物品本身。
- **反馈即冻结**：包装破损仅隔离反馈物品；使用后不适冻结**同品类同批号**的全部非终态物品，
  在途（候补/已确认/交接中）申请全部取消并通知，已取走（completed/已闭环）的借用保留并通知停用。
- **核查三分流**：个体过敏→恢复+品类风险提醒（借用强制确认）；物品问题→同批次报废；无法判定→恢复观察。
- **冻结期拦截**：被冻结物品不能申请、确认、交接、审核或撤回；大厅自动隐藏并给出替代/就医推荐；
  替代推荐只包含不同批号、在效期、当前有余量的同类物品。
- **库存锁定**：确认即锁数量，取消或闭环（归还/补充/赠予）后释放，候补按申请时间递补。
- **效期**：60 天黄色预警、30 天红色预警、过期大厅禁借并进入工作人员“待报废”清单。
- **时限**：确认后 24h（`PICKUP_WINDOW_HOURS`）未交接标红可释放；志愿者代送 6h（`DELIVERY_SLA_HOURS`）未达自动标红、可报备/改派。
- **全链路串联**：每个动作（含同批次冻结、核查结论、风险提醒）都写入同一物品时间线，三端记录对得上、可追溯。

1. **类型检查**：`npm run typecheck` —— 无错误。
2. **单元与流程测试**：`npm run test` —— **3 个测试文件、33 个用例全部通过**，覆盖：
   - 禁入规则（处方药关键词、拆封、冷链、过期、数量、60/30 天预警、缺批号提示）与同批次判定（大小写/空白、品类不同不算同批）；
   - 登记→审核→发布、禁入品登记失败；
   - **碘伏不适反馈后同批号（IDP-2508A）棉片+棉签立即冻结、不同批号（IDP-2511C）不受影响、在途申请取消/已取走保留、三方通知送达、冻结期各类操作拦截、替代推荐只出不同批次**；
   - **核查三分流：个体过敏恢复+风险提醒（未确认风险不能申请）、物品问题同批次报废、无法判定恢复、工作人员权限校验**；

## 建议的手工演示路径（约 3 分钟）

1. 默认身份**李建国**，打开「碘伏棉片」详情页，点“反馈包装破损 / 使用后不适”→ 选择“使用后不适”，
   勾选红肿/瘙痒、填写过敏史与用法、拍一张包装凭证照、选择是否就医后提交。
2. 观察右上角 🔔：切到**王秀兰**（棉签共享人+候补人）与**周敏**（棉片共享人）可分别看到冻结通知、候补取消通知；
   大厅顶部出现“碘伏有批次正在核查（IDP-2508A）”警示，推荐不同批号的“碘伏消毒液（小瓶）”与清水冲洗、卫生站、120 渠道。
3. 打开被冻结的棉片/棉签详情：显示冻结横幅，不能申请；切到**李建国 → 我的借用**，已取走的碘伏借用显示“立即停止使用”提醒。
4. 切**赵磊（社区工作人员）**：风险看板第一张卡即结构化核查信息（症状/过敏史/用法/照片/就医 + 2 件同批冻结物），
   先选择“**物品问题**”→ 同批次报废（或重置数据后改选“**个体过敏**”→ 恢复 + 品类风险提醒）。
5. 选“个体过敏”后，居民再打开任意碘伏物品申请时，必须额外勾选“品类个体过敏知情确认”；创可贴品类在种子数据中已有一条历史风险提醒可直接体验。
6. 志愿者视角确认不同批次碘伏（待审的 i8 / 在架的 i14）全程不受影响；任意时点可“重置演示数据”还原。
