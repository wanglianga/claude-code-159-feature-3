# 邻里药箱 · 社区共享借用 / 效期提醒 / 邻里互助（演示）

一个纯前端演示应用：居民登记家中多余但**未拆封**的常备非处方耗材（退热贴、碘伏、纱布、创可贴、口罩、体温计电池等），
经社区志愿者审核发布后，邻居可按症状场景申请借用，支持自取 / 志愿者代送 / 邻居门口无接触交接，交接拍照确认，
并按约定归还或补充。效期临近、多人争抢、超时未取、配送延误、共享人撤回、包装破损与疑似使用后不适均有对应处理流程。

> **社区只做物品流转和风险提醒，不做诊断建议。**
> 处方药、拆封药品、冷链药品、过期/包装破损物品**一律不能进入共享**。共享物品不替代就医。

技术栈：Vue 3（`<script setup>`）+ TypeScript + Pinia + Vue Router + Vite + Vitest。
所有数据保存在浏览器 `localStorage`，无后端依赖；底部“演示时钟”可快进，用于演示效期、超时与延误。

## 本期重点：使用后不适反馈 → 同批次立即冻结 → 核查处置闭环

借用人使用碘伏后反馈皮肤红肿时，系统按以下链路处理（`src/stores/medkit.ts`、`src/types.ts` 可核验）：

1. **扩展不适登记**：反馈时填写并留存 **症状表现、使用方式、过敏史、包装/生产批号照片、是否就医及就医情况**。
2. **同批次立即冻结**：按「品类 + 生产批号」定位，**同批次全部剩余物品页面立即冻结**（状态变“风险隔离待核”），
   停止新申请、确认与交接；等待/确认/交接中的申请自动取消，**已取走的借用保留**以便安全回访。无批号物品只冻结单件并提示无法定位同批次。
3. **多方通知**：冻结瞬间站内通知（顶部 🔔）推送给**共享人、社区工作人员、已借用居民**，以及候补被取消的居民；
   核查结论（下架/恢复/风险提醒）出来后再次通知。
4. **冻结期防扩散**：居民在大厅或详情页申请同类物品时被拦截，页面提示「当前批次正在社区核查中」，
   并**推荐其他安全替代物**（其他在架、在效期、有余量的品类，如纱布/创可贴）+ 非药物处理建议 + **就医渠道**（社区卫生服务中心、120、皮肤科）。
5. **社区核查三决策**：工作人员查看过敏史/包装照片/使用方式/就医记录后，判定
   **个体过敏**或**物品（批次）问题**：
   - 物品问题 → **同批次下架报废**，通知停止使用；
   - 个体过敏 → **恢复共享**，可选对该品类**加挂长期风险提醒**（过敏体质者慎用）；
   - 证据不足 → **维持冻结继续核查**。
6. **全链路留痕**：冻结、取消、批次下架/恢复、风险提醒都写入每件涉事物品的时间线，多角色记录对得上、可追溯。

## 本地启动

### 方式一：Docker / Compose（一键）

```bash
docker compose up --build      # 构建并启动，访问 http://localhost:8080
docker compose down            # 停止
```

### 方式二：Node 本地开发

```bash
npm install        # 如本机 npm 缓存权限异常，可加 --cache /tmp/npm-cache
npm run dev        # http://localhost:5173
```

其他命令：

```bash
npm run typecheck  # vue-tsc 严格类型检查
npm run test       # Vitest 单元/流程/冒烟测试（3 个文件、22 个用例）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览构建产物
```

## 页面与角色视图

- **药箱大厅 `/hall`**：按四个急用场景筛选 + 关键词/批号搜索；冻结品类显示醒目核查条与**安全替代物、就医渠道**；
  品类风险提醒以黄色横幅展示；冻结/隔离/过期物品不出现在卡片中。
- **物品详情 `/items/:id`**：展示生产批号、冻结批次信息、风险提醒；扩展反馈表单（症状/使用方式/过敏史/包装照片/就医）；
  借用记录、风险反馈（含工作人员核查结论）与完整时间线串联。
- **登记共享 `/register`**：填写品名、规格、**生产批号**、有效期、存放条件、是否整盒未开封、数量、地点、场景；
  实时规则校验，禁入品（处方药/口服注射药、拆封、冷链、过期、≤30 天临期）提交即被拦截。
- **我的共享 `/my-shares`**：登记物品状态与审核意见；确认/婉拒申请、发起交接、拍照确认、撤回。
- **我的借用 `/my-borrows`**：候补、取件开始/拍照确认、超 24h 未取红色警告、登记归还/补充/赠予。
- **志愿者工作台 `/volunteer`**：审核（机器规则二次提示）、配送拍照/报备延误/改派、超时催办与释放、候补递补。
- **社区工作台 `/staff`**：冻结批次总览、使用后不适核查（个体过敏/物品问题/证据不足 → 下架/恢复/风险提醒/继续冻结）、
  包装破损处置、过期报废、60/30 天效期分级、“其他耗材”双重复核、全链路追溯。
- **互助边界 `/guide`**：把“做什么/不做什么”、四类禁入、借用前四项确认、流程与异常处理（含同批次冻结核查）说清楚。

## 关键业务规则（可在 `src/rules.ts` 与 `src/stores/medkit.ts` 核验）

- **批次定位**：`batchKey = 品类 + 生产批号`；登记时建议填写批号，未填则出现不适只能单件隔离、无法自动联动同批次。
- **反馈即冻结**：疑似不适反馈提交后同品类同批号物品**立即**整体冻结并通知，不靠工作人员手动操作；
  核查期该品类**停止新申请**（大厅隐藏该品类卡片、申请接口拦截并引导安全替代物），同品类其他批号物品的候补申请一并取消；
  但物理隔离/下架只作用于同批号物品，其他批号冻结前已确认/交接中的借用继续履行。
- **库存锁定**：申请初始为“候补”；确认后锁定数量，取消或闭环（归还/补充/赠予）后释放，候补按申请时间递补。
- **效期**：60 天黄色预警、30 天红色预警、过期大厅自动禁借并进入工作人员“待报废”清单。
- **取件时限**：确认后 24 小时（`PICKUP_WINDOW_HOURS`）未完成交接 → 看板标红，可催办后取消释放给候补。
- **配送 SLA**：志愿者代送 6 小时（`DELIVERY_SLA_HOURS`）未完成 → 自动标红，可报备/改派。
- **撤回**：候补自动取消并通知；已确认/交接中/已取走的借用继续履行，不再接受新申请。
- **全链路串联**：每个动作写入同一物品时间线（`TimelineEvent`），三个角色视角不同但记录对得上、可追溯。
